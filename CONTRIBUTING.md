# Contributing to Decentralized Social Media Platform

Thank you for your interest in contributing! This document provides guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/Decentralized-Social-Media-Platform.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes thoroughly
6. Commit your changes: `git commit -m "Add your descriptive commit message"`
7. Push to your fork: `git push origin feature/your-feature-name`
8. Create a Pull Request

## Development Setup

Follow the instructions in [README.md](README.md) to set up your development environment.

## Code Style

- Use ES6+ JavaScript features
- Follow React best practices
- Use meaningful variable and function names
- Add comments for complex logic
- Ensure Solidity code follows security best practices

## Smart Contract Development

- Always write tests for new contract features
- Run `npm run compile` before committing
- Check for gas optimization opportunities
- Follow the Checks-Effects-Interactions pattern
- Document all public functions

## Frontend Development

- Keep components modular and reusable
- Use functional components with hooks
- Ensure responsive design
- Test with different wallet providers
- Handle loading and error states gracefully

## Testing

- Write tests for all new features
- Run `npm test` before submitting PRs
- Ensure all tests pass
- Aim for good code coverage

## Pull Request Guidelines

- Provide a clear description of changes
- Reference any related issues
- Include screenshots for UI changes
- Ensure CI/CD checks pass
- Keep PRs focused on a single feature/fix

## Security

- Report security vulnerabilities privately
- Never commit private keys or sensitive data
- Review code for common security issues
- Test contract upgradability if applicable

## Questions?

Feel free to open an issue for discussion or questions.
